How It Works

Messages are encrypted using a combination of Caesar cipher and Base64 encoding. The numeric key shifts each letter in the message, making it unreadable without the key.

Security Tips

  • Use strong numeric keys (4+ digits)
  • Share keys through secure channels
  • Change keys regularly
  • Don't reuse keys for different messages

Use Cases

  • Sensitive payment information
  • Confidential tenant data
  • Private administrative notes
  • Secure communication logs
